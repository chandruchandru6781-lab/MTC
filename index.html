📚 How to Start the Assessment Test

Step 1: Select Number of Teams

Click on one of the team count buttons (1, 2, 3, 4, or 5 teams) based on how many teams will participate in this assessment.

Step 2: Enter Team Names

After selecting the number of teams, input fields will appear. Enter the name for each team. These names will be displayed on the scoreboard during the quiz.

Step 3: Set Number of Questions

Enter the total number of questions you want in this assessment. You can set any number from 1 to 1000.

Step 4: Start Assessment

Click the "Start Assessment" button to begin. The quiz screen will appear with the first question.

During the Quiz:

  • Select Team: Choose a team from the dropdown menu
  • Select Answer: Click on the correct option
  • Next Question: Click "Next Question →" to go to the next question
  • Review: Click "Review Answers" button to see previously answered questions
  • Home: Click "🏠 Home" button to return to setup screen

💡 Tips:

  • Each team's score is tracked independently
  • Scores appear on the scoreboard panel on the left
  • You can access Tools menu to manage questions, videos, files, and themes
  • All answers are recorded and can be reviewed at the end
